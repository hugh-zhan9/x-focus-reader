# X Focus Reader

一个只在 `x.com` 运行的 Chrome 扩展。在原网页上过滤不想看的内容，用快捷键刷帖，阅读详情后回到原位置。

## Mac 上安装

1. 下载或克隆仓库。下载 ZIP 的话，先解压。
2. 在 Chrome 打开 `chrome://extensions`，打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选仓库中的 **`extension`** 文件夹（该文件夹直接包含 `manifest.json`）。
4. 刷新 `x.com`，从扩展工具栏图标打开设置。在「正在关注」「为你推荐」或 X 列表里试用。若你已经装了类似扩展，首次测试可先停用它以排除快捷键冲突。

## 功能

- **本地黑名单**：在帖子上的「阅读规则」菜单永久隐藏作者或隐藏 24 小时，支持撤销。可选把引用了被屏蔽作者的帖子也折叠，不改变 X 内的关注和拉黑关系。
- **内容过滤**：关键词包含匹配、话题精确匹配、内容类型；账号白名单只跳过内容规则，不跳过明确的黑名单。命中会显示折叠原因，可临时展开。
- **阅读进度**：用帖子 ID 保存位置，按主页不同时间线和各个列表分开记录。支持跳到已加载的上次位置；原帖没加载时提供打开原帖的链接，而不主动深滚。详情返回尽量还原到同一帖子及其屏幕偏移。
- **快捷键**：默认 J / K 下条 / 上条，Enter 打开，Esc 返回；可修改，输入内容时不拦截。
- **模式与备份**：关注、清爽、原版；规则和快捷键可导出、导入 JSON。阅读位置不会包含在规则备份里。

关注流按时间顺序显示时，「读到这里」标记仅在上次的具体帖子出现在本次列表时显示。推荐流会重新排序，不把它当成已读／未读分界。X 的布局、语言变体或虚拟加载可能改变可识别的帖子；找不到原帖不会冒险跳转到别的帖子。

## 隐私

无后台请求、无遥测、无 Cookie 权限，不调用 X 私有 API。设置和阅读进度存放在 Chrome 的本地扩展存储。同一 Chrome 个人资料下切换 X 账号会共用这份本地规则，不适合多人共用浏览器资料时作为隐私隔离。

## 开发

不依赖构建工具或第三方 npm 包。Node.js 20+：

```sh
npm run check
npm test
```

Chrome 中的手工回归：加载扩展，开启「正在关注」，在一条普通帖点开详情并返回；切换「为你推荐」再切回；滚动到加载新帖后按 J/K/Enter；在搜索框中输入同样字母；永久/24 小时屏蔽一位作者然后撤销；看一个引用帖以验证引文设置。关闭/重开页面验证恢复提示不会强制滚动。
