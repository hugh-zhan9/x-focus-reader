# X Focus Reader

一个只在 `x.com` 运行的 Chrome 扩展。在原网页上过滤不想看的内容，用快捷键刷帖，阅读详情后回到原位置。

## Mac 上安装

1. 登录有仓库访问权限的 GitHub 账号，从 [最新 Release](https://github.com/hugh-zhan9/x-focus-reader/releases/latest) 的 **Assets** 下载 `x-focus-reader-chrome.zip`，解压。
2. 在 Chrome 打开 `chrome://extensions`，打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选解压出的 **`x-focus-reader-chrome`** 文件夹（直接包含 `manifest.json`）。
4. 刷新 `x.com`，从扩展工具栏图标打开设置。在「正在关注」「为你推荐」或 X 列表里试用。若你已经装了类似扩展，首次测试可先停用它以排除快捷键冲突。

想试用最新提交，可从 [自动打包](https://github.com/hugh-zhan9/x-focus-reader/actions/workflows/package-extension.yml) 找到最近一次成功的 `main` 运行，在 **Artifacts** 下载。若之前已安装，备份规则后用新包内容替换原安装目录，再到扩展页点「重新加载」；不要另装一份，否则不会沿用原来的本地数据。也可以从源码加载仓库里的 `extension` 文件夹。

## 功能

- **展开阅读**：默认加宽桌面推文主栏（窄窗口保留原宽度）。识别到的普通图片按原顺序展开，保留比例，不裁长图；图片仍可点开查看。时间线的内联「Show more」自动展开，跳转链接、未载入的图片和受保护的媒体保留 X 原行为。「原版」模式恢复原有排版，并停止自动展开（已展开的正文刷新后恢复）。

- **本地黑名单**：点帖子操作区的屏蔽图标（悬停可看标签）即可持续隐藏该作者，支持撤销或在设置里移除。旧版的限时规则仍按原时间到期。可选把引用了被屏蔽作者的帖子也折叠，不改变 X 内的关注和拉黑关系。
- **内容过滤**：关键词包含匹配、话题精确匹配、内容类型；账号白名单只跳过内容规则，不跳过明确的黑名单。命中会显示折叠原因，可临时展开。
- **阅读进度**：用帖子 ID 保存位置，按主页不同时间线和各个列表分开记录。进入时间线会自动回到已加载的上次位置。首次打开页面时，如果留在原位且原帖未随时间线加载，会自动打开原帖一次；不会主动深滚。详情返回尽量还原到同一帖子及其屏幕偏移。
- **快捷键**：默认 J / K 下条 / 上条，Enter 打开，Esc 返回；可修改，输入内容时不拦截。
- **模式与备份**：关注、清爽、原版；规则和快捷键可导出、导入 JSON。阅读位置不会包含在规则备份里。

关注流按时间顺序显示时，「读到这里」标记仅在上次的具体帖子出现在本次列表时显示。推荐流会重新排序，不把它当成已读／未读分界。X 的布局、语言变体或虚拟加载可能改变可识别的帖子；找不到原帖不会跳到不相关的帖子。

## 隐私

没有后台数据请求（展开的图片由网页直接加载 X 图片 CDN）、无遥测、无 Cookie 权限，不调用 X 私有 API。设置和阅读进度存放在 Chrome 的本地扩展存储。同一 Chrome 个人资料下切换 X 账号会共用这份本地规则，不适合多人共用浏览器资料时作为隐私隔离。

## 开发

不依赖构建工具或第三方 npm 包。Node.js 20+：

```sh
npm run check
npm test
```

发布新版本时，更新 `extension/manifest.json` 和 `package.json` 的版本。推送与扩展版本一致的 `vX.Y.Z` 标签，或从 `main` 手动运行自动打包并填写 `release_tag`。测试和打包通过后，GitHub Actions 会将 ZIP 附到 GitHub Release。

Chrome 中的手工回归：加载扩展，开启「正在关注」，在一条普通帖点开详情并返回；切换「为你推荐」再切回；滚动到加载新帖后按 J/K/Enter；在搜索框中输入同样字母；屏蔽一位作者然后撤销；看一个引用帖以验证引文设置。关闭/重开页面验证自动回到原帖，提前滚动或按返回不会被强制跳走。
